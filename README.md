# adauchi(仮タイトル)

Unreal Engine 5とC++で個人制作中の3Dアクションゲームです。
依頼を受ける→ターゲットの制圧→報酬を得るというサイクルを最終的に実現したいと考えています。
現在は攻撃システムの基礎部分を実装しており、今後は被弾演出、敵AI、ゲームループの追加を予定しています。

## Implemented Features

- Sphere Overlapによる敵探索
- 内積による前方判定
- 最も近い敵の選択
- Line Traceによる遮蔽判定
- 敵への自動旋回・接近
- AnimNotifyとSphere Sweepによる攻撃判定
- ダメージ処理
